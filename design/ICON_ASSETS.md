# DawnCapture 图标资源清单

用于实现 `dawncapture-ui-prototype.html` 中 UI 的图标对照表。  
下列色值来自原型设计令牌。WinUI 可在运行时对 SVG / Fluent 图标着色；若从图标网站下载固色资源，请参考 **下载色值** 列。

---

## 设计色值（参考）

| 令牌 | 浅色 | 深色 | 常见用途 |
|------|------|------|----------|
| `--text` | `#1C2024` | `#F3F4F5` | 表面上的主要图标 |
| `--text-muted` | `#626971` | `#B5BAC0` | 导航、模式、文件夹 |
| `--text-faint` | `#858C94` | `#8F969E` | 箭头、搜索、辅助信息 |
| `--accent` | `#D85B42` | `#F07A61` | 激活 / 录制 / 品牌标识 |
| `--accent-hover` | `#BF4933` | `#FF8A70` | 强调色图标悬停 |
| `--control` | `#24282D` | `#F0F1F2` | 主按钮上的图标（较少） |
| `--danger` | `#C42B1C` | `#FF7669` | 关闭悬停、录制圆点 |
| `--surface` | `#FFFFFF` | `#292D32` | 图标背景（Logo 底块） |
| `--stroke-strong` | `#BDC2C8` | `#555C64` | Logo / 模式图标边框 |

**下载建议：** 需要在深浅色主题共用的 UI 图标，优先下载 **单色 SVG**，由应用设置 `Foreground` 着色。若网站只支持 PNG，可下载 **两套**（浅色列 + 深色列），或用 `--text-muted` 中性色下载一套。

## 汇总：需要下载什么

### 最小自定义集（推荐）

| 优先级 | ID | 数量 | 尺寸 | 色值说明 |
|--------|-----|------|------|----------|
| P0 | B1–B7 | 7 张 PNG + 1 张主源图 | 见第 1 节 | 完整品牌配色 |
| P1 | M1–M4 | 4 个图标 | 各 **20×20** | 未选中：`#626971`（或单色 SVG） |
| P2 | B2 | 1 套 Logo | **24**、**60** | 浅色底块上 accent `#D85B42` |

### 可跳过（Fluent / 系统默认）

第 2–9 节中标记 **可用默认** 的项，约 **20 个** — 按表格映射到 WinUI `SymbolIcon` 即可。

### 无需下载

标记为 **程序生成** 或 **Switch/控件** 的项 — 缩略图、窗口图标、开关、滚动条、录制指示条等。

## WinUI Fluent Symbol 速查

实现时可复制参考：

```xml
<!-- 导航 -->
Symbol="Video"              <!-- Capture / 录制 -->
Symbol="Library"            <!-- Recordings / 录像库 -->
Symbol="Setting"            <!-- Settings / 设置 -->
Symbol="Help"               <!-- About / 关于 -->

<!-- Capture 模式 -->
Symbol="FullScreen"         <!-- 全屏 -->
Symbol="Picture"            <!-- 窗口 -->
Symbol="Crop"               <!-- 区域 -->
Symbol="Microphone"         <!-- 纯音频 -->

<!-- 操作 -->
Symbol="Play" / "Pause" / "Stop"
Symbol="More"
Symbol="Find"
Symbol="OpenFolderHorizontal"
Symbol="Folder" / "FolderOpen"
Symbol="ChevronRight" / "ChevronUp"
Symbol="ClearNight" / "Sunny"
```
