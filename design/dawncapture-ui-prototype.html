Rotation while recording

The output keeps its original orientation; the picture is rotated back by the GPU and padded with letterbox bars. Shown once, in place — never a dialog.

Why a single file still works

Locking the orientation keeps the capture surface size constant → the encoder never restarts → the resolution never changes → one MP4 is valid. Whether the device rotates or letterboxes the content depends on the Android version and the vendor build — verify on real hardware.

The live monitor window — a recording entry point, not a remote control

Click the preview to pop it out as an always-on-top window. It carries its own record button: watch until something worth keeping appears, then record right there. When nothing is recording there is no floating dock — the dock only appears once a recording starts.

The record button

Always visible at the right of the title strip; the other controls appear on hover. Once recording, it becomes Stop in place — same position, same accent colour as the dock's stop button.

It records the phone stream only, at native resolution. Only one recording can run at a time: if the desktop is already recording, this button disables and says why.

Closing it does not stop the recording

The recorder owns the stream, the window only displays it — reopen it any time while recording continues.

Capture rules differ from the dock: the dock must be excluded from capture (WDA_EXCLUDEFROMCAPTURE), the monitor window must not be — otherwise "automatic composition" can never work.

Resize & zoom

The window is locked to the phone's aspect ratio — drag any edge or the bottom-right corner and it scales proportionally, never stretching.

The footer always reports Shown 142% · native 1080 × 2400, so upscaling past 100% is stated honestly. Recording the phone alone is unaffected by zoom; recording the desktop captures it at whatever size it is on screen.

Errors — each one says what to do next
Not authorised yet

The PC sees the device, but the phone has not confirmed the prompt.

Keep the phone unlocked next time you plug it in, and the prompt reappears. If it never shows, check Developer options → USB debugging.
Connection lost

The cable was unplugged, or the phone dropped the session.

Everything recorded so far is already saved. Plug the cable back in to continue into a new file.
Device not supported

Usually an older Android version, or a vendor build that has closed the required channel.

Requires Android 8.0 or newer; some custom ROMs need one extra switch in Developer options.
Phone is busy

Another mirroring tool (scrcpy, a vendor screen-share helper) is holding the device.

Close that program and press Recheck — no need to restart the PC or the phone.
